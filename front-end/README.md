# IFSul Estágios

Este projeto é uma aplicação web desenvolvida para facilitar a gestão e divulgação de oportunidades de estágio no Instituto Federal Sul-rio-grandense (IFSul), desenvolvido como trabalho final do Curso Técnico em Informática na disciplina de Projetos II. O objetivo da plataforma é de facilitar o processo de busca de vagas por parte dos alunos e oferecer um sistema que centralize as diversas vagas entre os Campi.

[Acesse a versão online](https://ifsul-estagios.vercel.app/)

## Funcionalidades

- **Cadastro e login de usuários** (estudantes, administradores (COPEX))
- **Busca de vagas de estágio** com filtros por cidade e curso
- **Inserção, edição e remoção vagas** por administradores
- **Sistema de autenticação** com proteção de rotas
- **Interface intuitiva e responsiva**

## Ferramentas e Tecnologias Utilizadas

- **React** (Vite) para o front-end
- **Node.js** e **Express** para o back-end
- **CSS** modularizado para estilização
- **JWT** para autenticação
- **ESLint** para padronização de código
- **Git** para controle de versão

## Aprendizados no Processo

Durante o desenvolvimento deste projeto, aprendi:

- Como estruturar uma aplicação full-stack separando front-end e back-end
- Implementação de autenticação com JWT e proteção de rotas
- Gerenciamento de estado e contexto no React
- Criação de componentes reutilizáveis e responsivos
- Utilização de ferramentas de lint e boas práticas de código
- Integração entre front-end e back-end via API REST
- Organização de código e colaboração usando Git

O projeto proporcionou uma experiência prática em desenvolvimento web, reforçando conceitos de segurança, usabilidade e arquitetura de software.
